# BIO-001 — Camera-to-Face-Detection Baseline

## Status

Initial implementation candidate.

## Scope

BIO-001 proves only this local vertical slice:

```text
Camera -> Frame Capture -> Face Detection -> Local Visualization -> Timing Metrics
```

It does **not** perform identification, verification, enrollment, biometric template storage,
authentication, liveness/PAD, cloud processing, or physical access control.

## Detector

The first detector adapter uses OpenCV's packaged frontal-face Haar cascade. This is a baseline
engineering dependency, not a production recognition or security model. The application depends on
a `FaceDetector` port so this implementation can be replaced without coupling later decision logic
to OpenCV.

## Run locally

Python 3.11–3.13 is supported by the project metadata.

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
python -m pip install -e ".[dev]"
bio-security detect --camera 0
```

Optional capture hints:

```bash
bio-security detect --camera 0 --width 1280 --height 720
```

Press `Q` or `ESC` to stop. The program does not save frames by default.

## Verification

Repository-only checks that do not require a physical camera:

```bash
ruff check src tests
mypy src
pytest
```

Hardware acceptance still requires execution on the target laptop with its actual camera. Record the
OS, Python version, CPU/RAM/GPU, camera, requested/actual resolution, detector version, and observed
latency metrics when that test is performed.

## Failure behavior

- Camera open failure returns a non-zero exit code with an explicit error.
- Frame read failure returns a non-zero exit code with an explicit error.
- Detector load failure returns a non-zero exit code with an explicit error.
- Operator `Ctrl+C`, `Q`, or `ESC` causes camera/window cleanup.

## Data handling

BIO-001 does not persist frames. `.gitignore` excludes local datasets, captures, result artifacts,
model artifacts, embeddings, and local SQLite/database files to reduce the chance of accidental
biometric-data commits.
